# 開発者ログイン入口の多段化 デザイン設計書

- **日付**: 2026-10-18
- **対象**: 開発者ログイン(/dev)の入口配置とユーザー側開発者操作の撤去
- **ブランチ**: `feat/dev-entry`（現 `master` = `c7535fe` 起点）

## 背景・目的

ユーザーホーム（`/user/home`）の最下部に、無認証でも押せる「dev: cache」リンク（→ `/dev/clear`）が露出しており、ユーザー側に開発者操作が見えている。これを撤去し、開発者ログイン(`/dev`)の入口は**管理者ログイン画面（`/admin`）の中**に置く。

これにより表面（トップ `/`・ホーム `/user/home`）には**管理者入口のみ**が見え、`/admin` まで到達した人だけが開発者ログインへ進める**多段階動線**になる。

## 確定した方針

| 項目 | 決定 |
|------|------|
| 開発者ログイン入口の位置 | `/admin`（管理者パスコード画面）内に「開発者の方はこちら →」リンク（→ `/dev`）を設置 |
| 表面の見え方 | トップ・ホームには管理者入口のみ。dev は管理者画面の先に隠れる |
| ユーザー側の開発者操作 | `/user/home` の「dev: cache」リンクを削除（ユーザー側から排除） |
| `/dev/clear` | dev 認証下にそのまま残す（URL直打ちで到達可）。今回は変更しない |

## 変更内容

### 1. `app/admin/page.tsx`（管理者パスコード画面）

既存のフッターリンク「← トップへ戻る」の近く（同じフッター領域）に、控えめなスタイルのリンクを追加：

- 文言：「開発者の方はこちら →」
- 遷移先：`/dev`
- スタイル：既存フッターの控えめな灰色・下線の小文字に合わせる（管理者画面のトーンを踏襲）。

ログイン処理・既存のUI/挙動は変更しない（リンク追加のみ）。

### 2. `app/user/home/page.tsx`（ユーザーホーム）

最下部の「dev: cache」リンクブロック（`<Link href="/dev/clear">dev: cache</Link>` を含む開発者用リンクの `div`）を**完全に削除**する。他のロジック・配色・ヘッダー（管理者ボタンを含む）は変更しない。

## スコープ外（YAGNI）

- `/dev/clear` 自体の変更・移動（dev 認証下のまま据え置き）。
- `/dev/console` からキャッシュ操作(`/dev/clear`)への導線追加（必要なら将来）。
- トップページ `/` への dev 入口追加（多段化方針により不要）。
- ホームヘッダーの管理者ボタンの変更。

## 検証

- `npm run build`（`ADMIN_SESSION_SECRET` / `DEV_SESSION_SECRET` / `DEV_PASSCODE` をダミー設定）で通過すること。
- `/admin` に「開発者の方はこちら」リンクが表示され `/dev` へ遷移すること、`/user/home` から「dev: cache」が消えていること（目視）。

## 未決・実装時に確定する細部
