# RPG冒険マップ デザイン設計書

- **日付**: 2026-10-18
- **対象**: スタンプラリーアプリ（5スタンプ表示のRPG冒険マップ化）
- **ブランチ**: `feat/rpg-adventure-map`

## 背景・目的

現状のスタンプ表示（`/user/stamps`）は縦1列のカードが並ぶだけで「スタンプラリー＝道のり」というマップ感がなく、初見の人に分かりにくい。5つのスタンプを **ロードマップ／RPG冒険マップ** として表現し、「今どこにいて、次どこへ行くか」が直感的に伝わるデザインへ変更する。

対象年齢は15歳想定（子供すぎず大人すぎず）。アプリの軽量・サクサク・堅牢という既存要件は維持する。

## 確定した方針

| 項目 | 決定 |
|------|------|
| 方向性 | RPG世界地図（冒険マップ風）。5ノードを左右ジグザグに配置し、曲線の道でつなぐ |
| 描画方式 | ハイブリッド：CSSグラデーション地形 ＋ SVG曲線の道 ＋ 絵文字装飾（🌲🌊⛰️）。画像素材はほぼ不要 |
| 配色 | エメラルド・クエスト（下記パレット） |
| 進行ルール | 自由順＋「次の目的地」強調。ハードロックなし、全ポイント常時タップ可能 |
| 適用範囲 | スタンプ画面＝本格マップ／ホーム画面＝新配色に調和（ミニ地図化） |
| ヘッダー | 上部 sticky スリムヘッダー ＋ 下部 fixed ボトムHUDバー（スマホ最適） |

### 配色パレット（エメラルド・クエスト）

| 用途 | HEX | 補足 |
|------|-----|------|
| 背景（上） | `#0f3d3e` | 深ティール |
| 背景（下） | `#14532d` | 深緑（縦グラデ） |
| 地形 | `#2f8f5b` | エメラルド |
| 海 | `#0e7490` | シアン |
| 道 | `#facc15` | 明るい金（達成区間の実線） |
| 宝/GOAL | `#fde047` | ライム金 |
| 達成ノード | `#10b981` | 発光緑リング |

## 画面設計

### スタンプ画面 `/user/stamps`

縦長の「地図キャンバス」を縦スクロール。上＝スタート（①）、下＝ゴール（⑤・宝箱）。下にスクロールするほど冒険が進む。

```
╔═══════════════════╗
║  スタンプの冒険    ║ ← sticky ヘッダー(半透明・スリム)
╟───────────────────╢
║   ╭───╮            ║
║   │①✓│🗺️ 制覇     ║ ← 達成=発光緑リング+✓
║   ╰─┬─╯            ║
║     ╲金の道(実線)  ║
║      ╭─┴─╮         ║
║ 制覇 │②✓│🏔️       ║
║      ╰─┬─╯         ║
║   ╱┈┈┈┘ 点線=未踏  ║
║  ╭─┴─╮             ║
║  │③！│🌸 ◀次はここ ║ ← 脈動する金リング+「！」
║  ╰─┬─╯             ║
║    ┊               ║
║   ╭┴──╮            ║
║   │④ │⛩️ 未踏の地  ║ ← 通常(タップ可)
║   ╰─┬─╯            ║
║     ┊🌲  🌊        ║ ← 装飾絵文字
║   ╭─┴─╮            ║
║   │⑤ │🎁 GOAL      ║ ← 宝箱/王冠
║   ╰───╯            ║
╟───────────────────╢
║ 2/5 制覇 ▮▮▯▯▯  更新 管理者 ║ ← fixed ボトムHUD
╚═══════════════════╝
```

#### ノードの3状態

| 状態 | 判定 | 見た目 | タップ |
|------|------|--------|--------|
| 制覇済み | スタンプ取得済み | 発光緑リング＋アイコン＋✓、手前の道が金色実線に点灯 | 不可（完了） |
| 次の目的地 | 未取得のうち最小番号 | 金の脈動リング＋「！」マーカー、「次はここ！」ラベル | 可 → QR表示 |
| 未踏の地 | その他の未取得 | 落ち着いた暗めノード、道は半透明点線、「？」 | 可 → QR表示 |

- ハードロックはしない（全ポイント常時タップ可能＝イベント運用の自由度維持）。
- 「次の目的地」ハイライトは未取得のうち最小番号を自動選択（①→②→…の道順感）。

#### 道（SVGルート）

- 縦に蛇行する1本のSVGパス。制覇済み区間は金色の実線、未踏区間は半透明の点線。
- スタンプ取得時に区間が金色に延びて点灯する演出（`stroke-dashoffset` アニメ `path-draw`）。

### ヘッダー／ナビゲーション（固定）

現状ヘッダーは固定されておらず、スクロールで流れて消える。これを以下に変更：

- **上部 sticky ヘッダー**（`sticky top-0`、半透明・スリム ~44px）：タイトル「スタンプの冒険」＋ニックネーム。
- **下部 fixed ボトムHUDバー**（`fixed bottom-0`、親指が届く位置）：
  - 左：進捗「X/5 制覇」＋ミニ進捗バー（常時可視）
  - 右：更新ボタン／管理者ボタン
  - iOS セーフエリア対応：`padding-bottom: env(safe-area-inset-bottom)`
- スクロール領域に下部バー分の `padding-bottom` を確保し、コンテンツがバーに隠れないようにする。

### ホーム画面 `/user/home`（調和）

全面刷新はせず新配色に寄せる：

- 進捗カードをティール系に。ミニ5枠を「ミニ地図」風（横一列の小ノードを点線でつなぐ）に。
- 「スタンプを集める →」ボタンを「冒険に出る 🗺️」に。
- ヘッダー・背景グラデを新パレットへ。
- ホームのヘッダーボタン群（更新・管理者）は現行構成を維持しつつ配色のみ調整。

## 技術構成

### コンポーネント分割

- **新規 `components/AdventureMap.tsx`**：マップSVG＋ノード描画を担当。
  - **入力（props）**: `stamps`（取得済みポイントの状態）、`animatingPoints`（アニメ中のポイント集合）、`generatingPoint`（QR生成中ポイント）、`onTapPoint(pointId)`（タップハンドラ）。
  - **責務**: 地形背景・SVGの道・5ノードの状態別描画・「次の目的地」判定とハイライト。表示専用で、データ取得やQR生成ロジックは持たない。
  - **依存**: 配色定数・ポイントアイコン/ラベル定数、既存 `StampAnimation`。
- **`app/user/stamps/page.tsx`**：Realtime購読・QR生成・プルリフレッシュ等のロジックは現状維持。**表示層（スタンプグリッド部分）を `AdventureMap` に差し替え**、ヘッダー/ボトムHUDを再構成。
- **`app/user/home/page.tsx`**：配色とミニ地図表示へ調整（ロジック変更なし）。
- **`app/globals.css`**：keyframe 追加（`beacon-pulse`＝次の目的地の脈動、`path-draw`＝道の点灯、ノード点灯）。既存の `stamp-*`／`complete-*`／`confetti`／`sparkle` keyframe はそのまま流用。

### 制約・非機能

- 重いライブラリ追加なし（SVG＋CSSのみ）。既存の判子/紙吹雪アニメを最大活用。
- Node20互換・`@supabase/supabase-js@2.49.4` 固定・PWA・既存API完全互換を維持。
- Realtime購読、QRモーダル、プルリフレッシュ、多重発火ガードは現行実装のまま。

## スコープ外（YAGNI）

- 入口ページ（`/user`）・管理画面のRPGテーマ化（今回は対象外）。
- 順番ハードロック機能（自由順のため不要）。
- 地図の一枚絵イラスト生成・外部画像素材（ハイブリッド方針のため最小限）。
- マップ上のキャラクター移動アニメ等の追加演出（将来検討）。

## 未決・実装時に確定する細部

- ノードのジグザグ配置の具体座標（SVG viewBox 設計）。
- 「制覇」バッジやラベル文言の最終調整。
- ゴール（宝箱）のオープン演出と既存コンプリート演出の接続タイミング。
