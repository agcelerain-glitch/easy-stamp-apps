# 開発者ログイン入口の多段化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ユーザーホームから「dev: cache」リンクを削除し、開発者ログイン(`/dev`)の入口を管理者ログイン画面(`/admin`)内に移すことで、表面上は管理者入口のみが見える多段階動線にする。

**Architecture:** 2ファイルのUI編集のみ。`app/admin/page.tsx` のフッターに `/dev` への控えめなリンクを1つ追加し、`app/user/home/page.tsx` 最下部の開発者用リンク(`/dev/clear`)ブロックを削除する。ロジック・ルーティング・認証は一切変更しない。

**Tech Stack:** Next.js 16 (App Router, client components) / React 19 / Tailwind CSS v4。依存追加なし。

## 検証方針

テストランナーは無い。検証は `npm run build`（型チェック＋コンパイル）＋目視。ビルドは `dev-session`/`admin-session` がモジュール読込時にシークレットを要求するため、env を付けて実行する：

- Bash: `ADMIN_SESSION_SECRET=build-dummy DEV_SESSION_SECRET=build-dummy DEV_PASSCODE=build-dummy npm run build`
- PowerShell: `$env:ADMIN_SESSION_SECRET="build-dummy"; $env:DEV_SESSION_SECRET="build-dummy"; $env:DEV_PASSCODE="build-dummy"; npm run build`

## Global Constraints

- Node 20 互換。依存追加なし。既存の配色/トーンを踏襲（管理者画面は gray 系、ホームは emerald 系）。
- `/admin` のログイン処理・`/user/home` のデータ取得やヘッダー（管理者ボタン含む）は変更しない。
- `/dev/clear` は変更しない（dev 認証下に据え置き）。トップページ `/` にも dev 入口は追加しない（多段化方針）。

### Task 1: 開発者入口を /admin へ移設し、ホームの dev:cache を削除

**Files:**
- Modify: `app/admin/page.tsx`（フッターのリンク領域）
- Modify: `app/user/home/page.tsx`（最下部の開発者用リンクブロックを削除）

**Interfaces:**
- Consumes: なし（既存ルート `/dev` は実装済み）
- Produces: なし（画面動線の最終形）

- [ ] **Step 1: `app/admin/page.tsx` のフッターに dev 入口を追加**

現在のフッター（ファイル末尾付近）：
```tsx
        <p className="text-center text-xs text-gray-300 underline">
          <a href="/">← トップへ戻る</a>
        </p>
```
を、次に置き換える（「← トップへ戻る」の下に控えめな dev リンクを追加）：
```tsx
        <div className="text-center space-y-1">
          <p className="text-xs text-gray-300 underline">
            <a href="/">← トップへ戻る</a>
          </p>
          <p className="text-xs text-gray-300 underline">
            <a href="/dev">開発者の方はこちら →</a>
          </p>
        </div>
```

- [ ] **Step 2: `app/user/home/page.tsx` の開発者用リンクブロックを削除**

次のブロック（最下部、`</main>` の直前）を**完全に削除**する：
```tsx
      {/* 開発者用リンク */}
      <div className="text-center py-4">
        <Link
          href="/dev/clear"
          className="text-[10px] text-emerald-200/20 hover:text-emerald-200/40 transition-colors"
        >
          dev: cache
        </Link>
      </div>
```
削除後、その直前の `</div>`（`下に引っ張って更新できます` を含むコンテンツ領域の閉じ）の次が `</main>` になる。`Link` はこのファイルの他所（ヘッダー・CTA等）で使われ続けるため import は残す（未使用化しない）。

- [ ] **Step 3: ビルド**

Run（Bash）: `ADMIN_SESSION_SECRET=build-dummy DEV_SESSION_SECRET=build-dummy DEV_PASSCODE=build-dummy npm run build`
Expected: 成功。型エラー・未使用 import 警告なし。

- [ ] **Step 4: 目視確認（任意）**

`npm run dev`（同 env）。`/admin` に「開発者の方はこちら →」が表示され `/dev` へ遷移すること、`/user/home` 最下部から「dev: cache」が消えていることを確認。ハング時はビルド成功を検証ゲートとする。
